# Loog Midnight

Two color themes for long sessions.

- **Loog Midnight** is a deep blue dark theme with teal accents.
- **Loog Daybreak** is a warm light theme with the same accent family.

Choose either one in **Settings → Theme**. A theme changes colors only; how the
editor behaves does not change.

## Syntax colors

Keywords, functions, types, strings, comments, numbers and properties each have
their own color in both themes, so the same code reads the same in a dark and a
light room. Comments are italic.

## Make your own

A theme is one small JSON file that starts from a built-in theme and names what
it changes. See `themes/midnight.json` in this package.
