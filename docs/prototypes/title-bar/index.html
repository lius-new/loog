Loog title bar prototype

The target for the title bar change. Click the project button, the gear and the branch to open their menus; hover the layout icon for its popover. Earlier exploration rounds are superseded by this file.

Title bar, left to right

  • Project button: tinted fill (accent at 16%, 26% on hover or open), solid accent tile with the project initial, name, chevron. Opens the project menu.
  • Path: the active file, segments separated by ›. One quiet style for every segment, including the file; a fill only on hover. Each segment opens that folder in the tree.
  • Notes, only when present: Restricted, then the update note. Unchanged.
  • Layout view: icon button, 32px wide, directly left of the window controls (right edge 108px from the window edge). The popover opens on hover, as today.
  • Window controls: unchanged.

Removed from the title bar

  • Repository / branch badge, and fetch, pull, push and publish.
  • Extensions and Settings buttons.
  • The Git operation message ("Fetching…", "Loading diff…").

Status bar, left side (new)

  • Gear: menu with Settings, Extensions, Keyboard Shortcuts, Command Palette. Amber dot while an extension has failed. Layout view is not in this menu.
  • Branch: main* with ahead and behind counts. Menu: branches, Pull, Push, Fetch (Publish when the branch has no upstream). Disabled while a Git operation runs.
  • Problems: unchanged.
  • Right side unchanged.

Project menu

  • Recent folders, each with its own tile; Open Folder…; Add Folder to Workspace….
  • The current project is marked "current".

Not decided yet

  • Path form: chevron segments are assumed. Other forms were shown (one plain string, last folders only, file icon) and none was chosen.
  • Tile color: always the accent, or a color derived from the folder name. The mock uses the accent for the current project and fixed colors for the others in the menu.
  • Where the Git operation message goes: proposed beside the branch in the status bar.
  • Long paths: proposed to collapse the middle into …, keeping the last two segments.
  • Moving Git actions out of the title bar reverses commit 84f1f9d.
